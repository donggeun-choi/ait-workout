# 홈 활동 기록

주간·월간 토글은 TDS Button을 사용하고 선택 상태를 aria-pressed로 제공한다. 기본값은 주간이다. 최근 운동 목록은 유지하고 토글은 상단 활동 카드의 조회 단위를 바꾼다.

- 주간: 기존 월요일~일요일 스트립, 완료 체크, 이번 주 운동 시간.
- 월간: 한국 시간 기준 이번 달을 월요일 시작 7열 달력으로 표현한다. 월초·월말의 빈 칸을 유지해 요일이 일치한다.
- 각 날짜의 완료 세트 수를 합산해 색상을 표시한다. 0 / 1~5 / 6~10 / 11~15 / 16세트 이상의 5단계이며 색이 진할수록 완료 세트가 많다.
- 오늘은 테두리로 구분한다. 날짜별 완료 세트는 접근성 이름과 툴팁으로도 제공한다. 날짜 칸은 조회용이고 클릭 버튼이 아니다.
- 헤더의 운동한 일수와 하단 운동 시간은 선택한 주간·월간 단위에 맞춘다. 실제 기록과 예시 기록은 기존 예시 보기 모드로 분리한다.
- 과거 달 탐색이나 날짜 클릭 상세는 이번 변경에 포함하지 않는다.
