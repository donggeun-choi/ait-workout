# 운동노트 전체 구현 및 main 병합

사용자 승인: 개인 기록과 공개 운동 인증·응원 전체 개발, 병렬 작업, main 병합(2026-10-03).

## 목표와 구조

기록 기반 1단계에 남은 개인 기능과 실제 서버 커뮤니티를 더한다. 개인 기록은 기존 기기 저장소에 유지하고 공개 인증은 서버 SQLite의 독립 스냅샷으로 저장한다. React DOM/TDS, Node 24 HTTP/SQLite, 공식 토스 로그인 mTLS를 사용한다. 배포·인증서 발급·운영 광고 ID 발급은 별도 외부 설정이며 코드 구현과 로컬 검증에 포함하지 않는다.

기준: `../specs/2026-10-01-workout-community-design.md`, `../../product-direction.md`. 원본 기록 보존, 로그인 없는 기록, 공개 정보 기본 최소화, 운영 개발 인증 비활성화, 입력을 막지 않는 타이머, 광고 대시보드 하단만을 지킨다.

## 병렬 경계와 리뷰

개인 기능은 App/model 및 개인 모듈, 커뮤니티 화면은 별도 Community/client 모듈, 서버는 server 디렉터리를 맡는다. App 통합은 개인 작업 완료 후 수행한다. 서버 계약은 `/api/community`이며 API 작성자가 계약 문서를 관리한다. 중복 파일 변경을 피하고 각 소유 파일만 커밋한다. 최종 검토는 권한 우회·개인정보 기본값·이전 저장 형식·실패 시 데이터 손실·중복 요청과 비동기 경쟁을 우선한다.

외부 운영 인증·광고·실기기는 설정/접근이 없으면 미검증 경계를 문서에 명확히 기록한다. 이를 로컬 모의 검증 성공으로 대체하지 않는다.
