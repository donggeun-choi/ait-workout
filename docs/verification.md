# 구현 검증

2026-10-01, 로컬 개발 서버와 별도 자동화 브라우저 프로필에서 확인했습니다.

## 기능

- 홈·운동·대시보드 탭 이동과 선택 상태 표시.
- 실제 기록이 없는 빈 상태, 별도 예시 데이터 보기.
- 상체 루틴 시작 → 벤치 프레스 60kg × 8회 완료 → 480kg 계산 → 운동 완료 → 상세 결과 → 홈 이동.
- 새로고침 후 저장된 기록 유지, 대시보드 1회·1세트·480kg 반영.
- 자유 운동 → 종목 검색 `스쿼트` → 종목 추가.
- 0회 입력 시 완료를 차단하고 입력 범위 안내.
- 올바른 횟수 입력 후 세트 완료 및 90초 휴식 표시.
- 주간 활동과 그래프는 월요일 기준.

## 화면

- 390 × 844 및 320 × 740 뷰포트에서 가로 넘침 없음.
- 검사한 화면의 11px 이하 텍스트 및 44px 미만 버튼 높이 없음.
- 하단 탭 34px 이상의 안전 여백, 본문 끝의 스크롤 공간 확보.
- 모달에 닫기 버튼 제공, 닫기 및 검색 동작 확인.
- 시스템 본문 폰트 적용, 메모의 이모지는 Tossface로 표시.
- 브라우저 오류 로그 없음.
- TDS Provider, Button, Badge, Asset.ContentIcon 사용. 브랜드 primary는 사용자가 명시한 블루 테마.

## 품질 점검 범위

| 화면     | 컨테이너     | 글자·터치     | 상태                          | 렌더                     |
| -------- | ------------ | ------------- | ----------------------------- | ------------------------ |
| 홈       | 로컬 웹 통과 | DOM 검사 통과 | 빈 상태·예시·저장 실패 안내   | 가로 넘침 없음           |
| 운동     | 로컬 웹 통과 | DOM 검사 통과 | 검색 결과 없음·입력 오류·완료 | 검색·세트 입력 확인      |
| 대시보드 | 로컬 웹 통과 | DOM 검사 통과 | 빈 통계·예시·기간 전환        | 320px에서 가로 넘침 없음 |

실기기에서 컨테이너 뒤로가기, 키보드에 따른 모달 위치, safe area는 아직 확인하지 않았습니다. 저장 공간 부족 및 손상 데이터 안내는 코드에서 처리하며, 브라우저 검증에서는 실제 저장 실패를 강제로 발생시키지 않았습니다. 네트워크 로딩 상태는 데이터가 동기 로컬 저장이므로 해당하지 않습니다. 등록용 이미지 자산 생성 및 콘솔 업로드는 이번 범위에 포함하지 않았습니다.

화면 캡처는 `docs/screenshots/`에 있으며 개발용 AIT 버튼이 포함되어 있습니다. 등록용 스크린샷이 아닙니다.

## 운동 화면 TDS 개편

- 운동 시작과 운동 저장은 TDS `BottomCTA.Single`로 하단 고정, 탭 위에 배치.
- 추천 루틴은 `#routines` 별도 화면에서 선택·구성 확인.
- `Top`, `ListRow`, `ListRow.Texts`, `Badge`, `TextArea`로 제목·목록·메모 대체.
- 하체 루틴 선택 후 운동 메인에 4개 운동·12세트가 반영되는 것을 실제 브라우저에서 확인.
- 루틴 선택은 임시 선택 후 CTA를 눌러 확정하며 돌아가기로 나가면 기존 선택 유지.
- 추천 루틴 화면에서는 하단 탭을 숨기고 선택 CTA를 제공.
- 세트별 숫자 입력과 완료 체크는 밀도 있는 기록 표를 위해 기존 사용자 정의 UI 유지.
